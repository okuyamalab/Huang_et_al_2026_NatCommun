**Software:** MATLAB R2020a (Windows), R2022a (macOS), and R2023b (macOS) (MathWorks).

**Dependencies:** Joint PCA, based on the code available at Zenodo (https://zenodo.org/records/11283463); `shadedErrorBar` by raacampbell (https://jp.mathworks.com/matlabcentral/fileexchange/26311-raacampbell-shadederrorbar); and `getCosineSimilarity(x,y)` (https://jp.mathworks.com/matlabcentral/fileexchange/62978-getcosinesimilarity-x-y).

The code used for the clustering analysis was originally developed by Huang et al. (2023) and is available at GitHub (https://github.com/okuyamalab/Huang_et_al_2023_NatCommun.).
